# High-Signal Self-Review Polish Pass

## Context

This is the **highest-leverage step** after addressing reviewer feedback.

Reviewers are optimized for *finding problems*. They are not optimized for *making the code excellent*.

You are.

## What the Polish Pass Covers (v2)

- Documentation (exported + complex internal)
- Naming & clarity
- Error handling & edge cases
- Performance hot paths
- Test quality (not just coverage quantity)
- Architectural consistency

Full detailed checklist will be merged from the original loop-review `cookbook/polish-pass.md`.

This pass is **strongly recommended** even on small PRs.
